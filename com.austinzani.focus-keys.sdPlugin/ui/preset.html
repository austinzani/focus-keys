Choose contrasting colors. The background is shared by all three styles for this key. On the sweep, the number changes to black or white for readability.

Alerts — shared by all timer keys

Leave the text empty for “Time's up: {minutes}-minute timer finished.” {minutes} becomes the timer's length. The notification is silent; only the sound above plays.

Notifications come from Focus Keys. The first one makes macOS ask for permission; allow it. If no banner appears, allow Focus Keys in System Settings › Notifications. If the plugin's notification helper can't run, the banner comes from Script Editor instead. A Focus mode can hide or delay banners. The timer and sound work either way.

Focus — shared by all timer keys

The plugin can't set Focus itself; it runs your shortcuts. In the Shortcuts app, make one with Set Focus turning your work Focus on (run on start and resume), and optionally one turning Focus off (run on pause, cancel and finish). With no end shortcut, Focus is left as it is. The end shortcut only runs after the start shortcut ran, or was stopped at the 30-second limit (it may have set Focus already); not after it was missing or failed.

Your previous Focus is not restored, and a Focus you change by hand (or by schedule) during a timer is not detected: the end shortcut runs anyway and may change it. This includes recovery: if a timer finished while the Mac slept or Stream Deck was closed, the end shortcut runs once when the plugin is back, however long ago that was. Switching to another preset keeps Focus on. Break keys never switch Focus on; starting a break during work runs the end shortcut. If “Share across devices” is on in Focus settings, these changes also apply to your other Apple devices. A Focus may hide the completion banner unless Focus Keys is allowed; the sound still plays.
