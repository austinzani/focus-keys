Alerts — shared by all timer keys

Leave the text empty for “Time's up: {minutes}-minute timer finished.” {minutes} becomes the timer's length. The notification is silent; only the sound above plays.

macOS shows these notifications as coming from Script Editor. The first one may ask for permission. If no banner appears, allow Script Editor in System Settings › Notifications. A Focus mode can hide or delay banners. The plugin can't tell whether a banner was shown; the timer and sound work either way.
